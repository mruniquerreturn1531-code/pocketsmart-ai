## 🌐 GitHub & Cloud Deployment

### 1. Push to GitHub
```powershell
git init
git add .
git commit -m "Initial commit: PocketSmart AI Cyber-Emerald Edition"
git branch -M main
git remote add origin https://github.com/YOUR_FRIENDS_USERNAME/pocketsmart-ai.git
git push -u origin main
```

### 2. Deploy on Render
1. Connect GitHub repository to Render (Free Web Service).
2. Build Command: `pip install -r requirements.txt`
3. Start Command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
4. Deploy!
